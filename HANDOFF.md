## BRIGHT Runner Notes

The evaluator is:

- exact MaxSim
- BRIGHT-aware
- prompt-aware for `ColBERT-Zero`
- resumable
- document-cache aware

Implementation details:

- query/document prompt handling: [bright_reasonir.py](/home/rbw/repo/pylate/examples/evaluation/bright_reasonir.py#L430)
- per-model per-task document cache: [bright_reasonir.py](/home/rbw/repo/pylate/examples/evaluation/bright_reasonir.py#L309)
- resume from `--output_json`: [bright_reasonir.py](/home/rbw/repo/pylate/examples/evaluation/bright_reasonir.py#L446)
- skip completed tasks: [bright_reasonir.py](/home/rbw/repo/pylate/examples/evaluation/bright_reasonir.py#L451)
- GPT-4 query-length mapping from the `Reason-ModernColBERT` model card: [bright_reasonir.py](/home/rbw/repo/pylate/examples/evaluation/bright_reasonir.py#L61)

Important caveat:

- `torch.load(..., map_location=model.device)` means loading cached document chunks onto the active device. This is correct, but on a weaker GPU or under memory pressure it may still be slow.
- The cache key includes model path slug, task, document length, chunk size, and document batch size. If those change, the cache is intentionally not reused.
